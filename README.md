## Installation

1. Download an APK to an Android device.
2. If prompted, allow installation from the source used to download the file.
3. Open the APK and follow Android’s installation prompts.

Only install APKs from sources you trust. Verify the SHA-256 checksum when possible.

## Repository scope

This repository contains Android release artifacts and release documentation only. It is intentionally separate from the Visold blockchain source repositories and does not modify or replace the Visold codebase.
