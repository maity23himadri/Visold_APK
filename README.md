# Visold Android APK

Standalone public distribution repository for the **Visold Android application**.

## Download

Download the Android package from [`releases/Visold-Android-v1.0(1).apk`](releases/Visold-Android-v1.0%281%29.apk).

## Version

- **Application release:** v1.0
- **Package format:** Android APK
- **Included ABI:** `arm64-v8a`
- **SHA-256:** `afe3277b6aa6450bc2faeccde377bd9f0f0b0b75c92ee27be5dfc6240e71c365`

## Installation

1. Download the APK to an Android device.
2. If prompted, allow installation from the source used to download the file.
3. Open the APK and follow Android’s installation prompts.

Only install APKs from sources you trust. Verify the SHA-256 checksum when possible.

## Repository scope

This repository contains the Android release artifact and release documentation only. It is intentionally separate from the Visold blockchain source repositories and does not modify or replace the Visold codebase.
